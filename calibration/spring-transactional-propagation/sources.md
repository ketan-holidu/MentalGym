# Sources

The documents this concept was tested on, all from the Spring Framework reference:

- Using @Transactional — https://docs.spring.io/spring-framework/reference/data-access/transaction/declarative/annotations.html
- Transaction Propagation — https://docs.spring.io/spring-framework/reference/data-access/transaction/declarative/tx-propagation.html
- `<tx:advice/>` Settings — https://docs.spring.io/spring-framework/reference/data-access/transaction/declarative/txadvice-settings.html

The fetched text snapshots stay out of git (see `.gitignore`) rather than republishing someone else's
documentation. They live in the database behind the MCP server, and `/mg-add` refetches them from these URLs.
